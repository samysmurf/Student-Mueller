## Manuelle Umsetzung

Die verfügbare GitHub-Verbindung kann Repository-Dateien ändern, aber nicht den About-Text oder Topics in den Repository-Einstellungen aktualisieren.

Manuelle Schritte:
1. Repository auf GitHub öffnen.
2. Im About-Bereich das Zahnrad beziehungsweise „Edit repository details“ öffnen.
3. Die empfohlene Beschreibung einfügen.
4. Die Topics einzeln ergänzen.
5. Änderungen speichern und anschließend die öffentliche Repository-Seite kontrollieren.
